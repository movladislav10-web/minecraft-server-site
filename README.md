# MineServer — стартовый прототип

Это фронтенд-прототип сайта Minecraft-сервера с:
- главной страницей;
- правилами;
- информацией;
- магазином и корзиной;
- заявками;
- техподдержкой;
- личным кабинетом;
- отдельной админ-панелью;
- настройкой основных цветов темы.

## Запуск

Открой `index.html` в браузере.

Админ-панель: `admin.html`.

## Важно

Это пока UI-прототип: реальные аккаунты, база данных, платежи, Minecraft API, баланс и сохранение настроек на сервере ещё не подключены.

Следующий этап — перенести этот интерфейс на полноценный backend + базу данных и подключить авторизацию, платежи и интеграцию с Minecraft.
